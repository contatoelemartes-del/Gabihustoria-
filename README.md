# Gabrielle Salvatore

RPG de The Vampire Diaries em que a Gabi cria e interpreta a Gabrielle Salvatore. Os outros personagens são todos IA.

O app é um único arquivo, `index.html`, publicado como artifact no Claude. Ele usa a IA da própria conta Claude, então não tem custo de API.

Abas: História (modo turnos), Insta, Twitter, DMs e Ficha.

O progresso fica salvo na conta Claude de quem abre a página. Cada pessoa tem um save privado, e há uma cópia neste aparelho como reserva.
